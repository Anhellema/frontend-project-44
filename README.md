# Brain Games

Это набор из **5 простых математических игр** в командной строке.  
Ты отвечаешь на вопросы — если дашь **3 правильных ответа подряд**, победишь!

## Какие есть игры?

1. **Чётное или нечётное?** — Угадай, чётное число или нет  
2. **Калькулятор** — Посчитай выражение, например: `4 + 10`  
3. **НОД** — Найди наибольший общий делитель двух чисел  
4. **Прогрессия** — Угадай, какое число пропущено: `2 4 6 8 __ 12`  
5. **Простое число?** — Ответь: "yes", если число простое, иначе "no"

---

## Что нужно для запуска?

- Компьютер с **Node.js** (версия 13 или новее)  
  [Скачать Node.js](https://nodejs.org/)

## Как установить?

В корневой директории открой **терминал** (командную строку) и введи:

**make install**

## Как играть?

В корневой директории введи в **терминал** (командную строку):

### 1. Чётное/нечётное
node bin/brain-even.js

### 2. Калькулятор
node bin/brain-calc.js

### 3. НОД
node bin/brain-gcd.js

### 4. Прогрессия
node bin/brain-progression.js

### 5. Простое число
node bin/brain-prime.js

### 6. Просто приветствие
make brain-games
